# 论文文件存储说明

## 目录说明

此目录用于存储已下载和解析的论文PDF文件。

## 文件处理策略

### 版本控制
- **PDF文件不纳入版本控制**：PDF文件体积大，已通过.gitignore排除
- **仅保留目录结构**：确保papers目录存在，便于程序运行

### 文件来源
论文文件通过以下方式获取：
1. 用户添加论文URL
2. 系统自动下载PDF文件
3. 解析并提取文本内容
4. 生成词汇和摘要数据

### 文件命名规则
```
paper_{论文标题}.pdf
```

### 注意事项
- 论文文件仅用于本地解析，不参与小程序编译
- 解析完成后，论文内容已转换为结构化数据存储在数据库中
- 如需重新解析，可通过后台系统重新下载

## 数据流程

```
论文URL → 下载PDF → 解析文本 → 提取词汇 → 存储到数据库 → 注入小程序
```

PDF文件在此流程中仅作为中间文件，最终数据以结构化形式存储。
