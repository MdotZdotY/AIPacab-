AI Pacab+ 后台论文分析系统 - 操作指南
===============================================

## 环境准备
1. 确保Python已安装并添加到环境变量
2. 确保虚拟环境已创建并激活

## 启动系统步骤

### 1. 打开命令提示符 (cmd)
- 按 Win + R，输入 cmd，回车
- 或者按 Win + X，选择"命令提示符"

### 2. 进入项目目录
```cmd
cd d:\Dev\AI_Vocabulary_Learning
```

### 3. 激活虚拟环境
```cmd
.venv\Scripts\activate.bat
```
看到提示符变为 (.venv) 表示激活成功

### 4. 进入backend目录
```cmd
cd backend
```

### 5. 启动后台服务
```cmd
python start.py
```

## 系统操作菜单

启动成功后，系统会显示以下菜单：
```
可用操作:
1. 处理待处理论文
2. 添加新论文
3. 查看系统状态
4. 创建小程序更新文件
5. 退出
```

### 常用操作说明：

**操作 1 - 处理待处理论文**
- 自动下载论文PDF
- 提取文本内容
- 调用LLM分析论文
- 提取GRE/TOEFL/IELTS/AI词汇
- 更新论文状态

**操作 3 - 查看系统状态**
- 显示系统版本信息
- 显示论文统计信息
- 检查配置状态

**操作 4 - 创建小程序更新文件**
- 生成小程序数据更新包
- 包含新的论文和词汇数据

## 常见问题解决

### 问题1：虚拟环境未激活
**症状**：提示符没有显示 (.venv)
**解决**：重新执行激活命令
```cmd
.venv\Scripts\activate.bat
```

### 问题2：Python命令不可用
**症状**：提示 'python' 不是内部或外部命令
**解决**：
1. 检查Python是否安装
2. 检查环境变量PATH
3. 重启命令提示符

### 问题3：模块导入错误
**症状**：ModuleNotFoundError
**解决**：
```cmd
pip install -r requirements.txt
```

### 问题4：论文处理失败
**症状**：LLM分析失败或下载失败
**解决**：
1. 检查网络连接
2. 检查API配置
3. 重置论文状态为pending

## 文件位置说明

- 配置文件：backend/config/config.json
- 论文列表：backend/config/papers_list.csv
- 下载的论文：backend/papers/
- 日志文件：backend/logs/

## 快速重启命令序列

如果需要快速重启，可以依次执行：
```cmd
cd d:\Dev\AI_Vocabulary_Learning
.venv\Scripts\activate.bat
cd backend
python start.py
```

## 注意事项

1. 每次操作前确保虚拟环境已激活
2. 处理论文时保持网络连接稳定
3. 如果遇到错误，先查看日志信息
4. 定期备份配置文件和数据
