# 云开发部署指南

## 概述

本指南将帮助您完成AI词汇学习小程序的云开发环境配置和云函数部署。

## 前置条件

1. **微信开发者工具**：确保已安装最新版本
2. **小程序账号**：需要有小程序AppID
3. **云开发服务**：需要在小程序管理后台开通云开发服务

## 第一步：配置云开发环境

### 1.1 开通云开发服务

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 进入您的小程序管理后台
3. 点击"开发" → "开发管理" → "云开发"
4. 点击"开通"按钮
5. 创建云环境：
   - 环境名称：`AI词汇学习环境`
   - 环境ID：`cloudbase-2g7pmtv3e63f7151`（或使用系统生成的ID）

### 1.2 配置项目云开发

1. 在微信开发者工具中打开项目
2. 点击工具栏中的"云开发"按钮
3. 选择您刚创建的云环境
4. 确认环境配置正确

## 第二步：创建数据库集合

### 2.1 创建vocabulary集合

1. 在云开发控制台中，点击"数据库"
2. 点击"添加集合"
3. 集合名称：`vocabulary`
4. 权限设置：选择"所有用户可读，仅创建者可写"

### 2.2 设置数据库权限

```json
{
  "read": true,
  "write": true
}
```

## 第三步：部署云函数

### 3.1 安装依赖

1. 在微信开发者工具中，右键点击`cloudfunctions/vocabularyManager`文件夹
2. 选择"在终端中打开"
3. 执行以下命令安装依赖：

```bash
npm install
```

### 3.2 部署云函数

1. 右键点击`cloudfunctions/vocabularyManager`文件夹
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 3.3 验证部署

1. 在云开发控制台中，点击"云函数"
2. 确认`vocabularyManager`函数已部署成功
3. 状态应显示为"正常"

## 第四步：测试云开发功能

### 4.1 使用测试页面

1. 在微信开发者工具中编译项目
2. 在模拟器中打开测试页面：`pages/test-cloud/test-cloud`
3. 点击"运行所有测试"按钮
4. 检查测试结果是否全部通过

### 4.2 手动测试

1. 在管理页面中，点击"同步管理"按钮
2. 尝试"同步到云端"功能
3. 检查云开发控制台中的数据库是否出现数据

## 第五步：配置云开发权限

### 5.1 设置云函数权限

1. 在云开发控制台中，点击"设置" → "权限设置"
2. 确保云函数有足够的权限访问数据库
3. 设置合适的调用频率限制

### 5.2 配置安全规则

在数据库的`vocabulary`集合中设置安全规则：

```json
{
  "read": "auth.openid != null",
  "write": "auth.openid != null"
}
```

## 常见问题解决

### 问题1：云函数部署失败

**解决方案**：
1. 检查网络连接
2. 确认云开发环境配置正确
3. 检查云函数代码是否有语法错误
4. 重新安装依赖并部署

### 问题2：数据库访问权限错误

**解决方案**：
1. 检查数据库集合权限设置
2. 确认云函数有访问数据库的权限
3. 检查安全规则配置

### 问题3：云开发环境未选择

**解决方案**：
1. 在微信开发者工具中点击"云开发"按钮
2. 选择正确的云环境
3. 重启微信开发者工具

### 问题4：云函数调用失败

**解决方案**：
1. 检查云函数是否已正确部署
2. 查看云开发控制台的错误日志
3. 确认函数名称和参数正确

## 性能优化建议

### 1. 数据库优化

- 为常用查询字段创建索引
- 合理设置分页大小
- 避免一次性查询大量数据

### 2. 云函数优化

- 合理设置超时时间
- 优化函数执行逻辑
- 使用批量操作减少数据库调用

### 3. 缓存策略

- 合理使用本地缓存
- 实现增量同步机制
- 避免频繁的云端数据获取

## 监控和维护

### 1. 监控指标

- 云函数调用次数和成功率
- 数据库读写性能
- 用户活跃度

### 2. 定期维护

- 清理无用的云函数版本
- 优化数据库查询性能
- 更新依赖包版本

## 故障排除

### 1. 查看日志

1. 在云开发控制台中查看云函数日志
2. 检查数据库操作日志
3. 分析错误信息

### 2. 回滚操作

如果新版本出现问题，可以回滚到之前的云函数版本：

1. 在云开发控制台中选择云函数
2. 点击"版本管理"
3. 选择之前的稳定版本进行回滚
