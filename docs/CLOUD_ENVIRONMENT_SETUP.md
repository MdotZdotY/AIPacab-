# 云开发环境配置指南

## 问题：cloudfunctions显示"（未选择环境）"

### 解决方案

#### 方法一：通过微信开发者工具界面配置

1. **打开微信开发者工具**
2. **点击工具栏中的"云开发"按钮**
   - 位置：工具栏右侧，云朵图标
   - 如果没有看到，请确保项目已正确配置云开发

3. **在云开发面板中**：
   - 点击"选择环境"按钮
   - 从下拉列表中选择您的环境：`cloudbase-2g7pmtv3e63f7151`
   - 如果列表中没有您的环境，点击"添加环境"

4. **添加环境**（如果需要）：
   - 环境ID：`cloudbase-2g7pmtv3e63f7151`
   - 环境名称：可以自定义，如"AI词汇学习环境"

#### 方法二：通过项目设置配置

1. **在微信开发者工具中**：
   - 点击菜单栏的"工具" → "项目设置"
   - 或者右键点击项目根目录，选择"项目设置"

2. **在项目设置中**：
   - 找到"云开发"选项卡
   - 选择您的云环境：`cloudbase-2g7pmtv3e63f7151`

#### 方法三：检查云开发控制台

1. **登录微信公众平台**
2. **进入小程序管理后台**
3. **点击"开发" → "开发管理" → "云开发"**
4. **确认环境状态**：
   - 环境ID：`cloudbase-2g7pmtv3e63f7151`
   - 环境状态：正常
   - 资源使用情况：正常

### 验证配置是否成功

配置完成后，您应该看到：

1. **cloudfunctions文件夹不再显示"（未选择环境）"**
2. **右键点击cloudfunctions/vocabularyManager文件夹时**：
   - 应该能看到"上传并部署：云端安装依赖"选项
   - 不再显示"未选择环境"的错误

3. **在云开发面板中**：
   - 显示正确的环境名称
   - 可以看到云函数列表

### 常见问题排查

#### 问题1：看不到云开发按钮
**解决方案**：
- 确保项目配置中已启用云开发
- 检查`project.config.json`中的`"cloud": true`配置
- 重启微信开发者工具

#### 问题2：环境列表为空
**解决方案**：
- 确认您已在小程序管理后台开通云开发服务
- 确认环境ID是否正确：`cloudbase-2g7pmtv3e63f7151`
- 检查小程序AppID是否匹配

#### 问题3：权限不足
**解决方案**：
- 确认您是小程序的管理员或开发者
- 检查云开发控制台的权限设置
- 联系小程序管理员授权

### 配置完成后的下一步

1. **部署云函数**：
   - 右键点击`cloudfunctions/vocabularyManager`
   - 选择"上传并部署：云端安装依赖"

2. **测试云函数**：
   - 使用我们创建的测试页面验证功能
   - 页面路径：`pages/test-cloud/test-cloud`

3. **创建数据库集合**：
   - 在云开发控制台中创建`vocabulary`集合
   - 设置适当的读写权限

### 测试步骤

1. **打开测试页面**：
   ```javascript
   // 在任意页面中添加跳转代码
   wx.navigateTo({
     url: '/pages/test-cloud/test-cloud'
   })
   ```

2. **运行测试**：
   - 点击"运行所有测试"按钮
   - 查看测试结果

3. **检查控制台**：
   - 查看是否有错误信息
   - 确认云函数调用是否成功

### 注意事项

1. **环境ID保密**：
   - 不要将环境ID分享给不相关的人员
   - 在生产环境中注意数据安全

2. **资源使用**：
   - 注意云开发资源的使用量
   - 合理设置数据库权限

3. **网络连接**：
   - 确保网络连接正常
   - 某些网络环境可能需要配置代理

2. 查看微信开发者工具的控制台错误信息
