# AI Pacab+

一个专门为AI词汇学习设计的微信小程序，帮助用户系统性地学习和记忆AI相关的专业词汇。

## 功能特色

### 🎯 多模式学习
- **复习模式**: 针对已学词汇进行巩固复习
- **测试模式**: 通过选择题测试词汇掌握程度
- **随机模式**: 随机学习所有词汇

### 📊 智能统计
- 学习进度跟踪
- 正确率统计
- 分类学习统计
- 学习趋势分析

### 🗂️ 分类管理
- GRE高频词
- TOEFL高频词
- AI专业词汇
- 支持自定义分类

### 📱 用户友好
- 现代化UI设计
- 流畅的交互体验
- 支持发音播放（开发中）
- 例句和翻译展示

## 项目结构

```
AI_Vocabulary_Learning/
├── app.js                 # 小程序入口文件
├── app.json              # 小程序配置文件
├── sitemap.json          # 站点地图配置
├── pages/                # 页面目录
│   ├── index/           # 首页
│   ├── study/           # 学习页面
│   ├── manage/          # 管理页面
```

## 页面功能

### 首页 (index)
- 学习统计概览
- 快速开始学习
- 最近学习记录
- 分类统计展示

### 学习页面 (study)
- 多种学习模式切换
- 词汇卡片展示
- 渐进式信息显示
- 学习进度跟踪

### 管理页面 (manage)
- 词汇增删改查
- 分类筛选
- 搜索功能
- 批量管理

### 统计页面 (stats)
- 详细学习统计
- 分类学习分析
- 学习趋势图表
- 学习建议

### 测试页面 (test)
- 选择题测试
- 实时得分统计
- 测试结果分析
- 错题回顾

## 技术特点

- **微信小程序框架**: 原生开发，性能优异
- **模块化设计**: 代码结构清晰，易于维护
- **响应式布局**: 适配不同屏幕尺寸
- **本地数据存储**: 使用微信小程序本地存储

## 开发环境

- 微信开发者工具
- 小程序基础库 2.0+
- 支持ES6语法

## 安装和运行

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具
3. 导入项目目录
4. 输入AppID（可使用测试号）
5. 点击编译运行

## 数据说明

项目内置了5个示例词汇：
- artificial intelligence (人工智能)
- machine learning (机器学习)
- neural network (神经网络)
- algorithm (算法)
- optimization (优化)

用户可以通过管理页面添加更多词汇。
