## 📱 项目简介

AI Pacab+ 是一款专为AI论文阅读设计的词汇学习小程序，帮助用户快速掌握AI领域专业词汇，提升论文阅读效率。

### 🎯 核心特色

- **AI专业词汇库**：涵盖GRE、TOEFL、IELTS及AI领域专有词汇
- **学习进度管理**：基于学习次数的复习机制（学习5次后进入复习模式）
- **论文词汇关联**：词汇与具体论文关联，学以致用
- **学习进度追踪**：详细的学习统计和进度分析
- **朋友圈分享**：生成精美的学习成果分享卡片

## 🚀 功能模块

### 1. 首页概览
- **学习统计**：总词汇量、已掌握词汇、学习天数
- **分类统计**：GRE、TOEFL、IELTS、AI专业词汇分类统计
- **快速开始**：一键进入学习模式

### 2. 词汇学习
- **复习功能**：固定频率
- **测试题型**：选择题
- **即时反馈**：答题后立即显示正确答案和解释
- **进度保存**：自动保存学习进度和正确率

### 3. 论文管理
- **论文列表**：展示所有可学习的论文
- **论文详情**：查看论文信息和相关词汇
- **阅读进度**：追踪每篇论文的阅读状态

### 4. 词汇管理
- **状态管理**：学习中、复习中、已掌握三种状态
- **分类筛选**：按词汇分类进行筛选和管理
- **搜索功能**：快速查找特定词汇

### 5. 学习统计
- **学习概览**：总学习时长、周平均时长等
- **分类统计**：各分类词汇的掌握情况
- **学习趋势**：可视化学习进度图表
- **分享功能**：生成朋友圈分享卡片

## 📱 使用指南

### 首次使用
1. 打开小程序，自动加载内置词汇库
2. 在首页查看学习概览
3. 点击"背单词"进入词汇学习模式、“读论文”进入论文阅读模式
4. 完成词汇练习，系统自动记录进度

### 日常学习
1. 每日复习已经进入复习词汇库的词汇
2. 学习新词汇，提升词汇量
3. 查看学习统计，了解进度
4. 阅读论文，应用所学词汇

## 🛠 后台论文分析系统

### 系统概述
为了提供更丰富、更专业的论文分析内容，我们正在开发一个后台系统，通过LLM自动分析论文并提取相关词汇，然后通过小程序更新机制注入到用户本地设备。

### 核心功能
- **论文管理**: 维护论文列表，自动抓取论文内容
- **LLM分析**: 生成背景解读、关键概念、论文亮点
- **词汇提取**: 自动提取GRE/TOEFL/IELTS/AI专业词汇
- **数据注入**: 通过小程序更新机制注入到用户本地

### 技术特点
- **完全本地化**: 所有数据最终存储在用户本地设备
- **零破坏性**: 不影响现有小程序功能和UI
- **数据兼容**: 完全沿用现有数据结构
- **成本可控**: LLM调用成本完全可控

### 详细文档
完整的系统设计和技术方案请参考：[PRD_后台论文分析系统.md](./PRD_后台论文分析系统.md)

### 快速开始
```bash
# 进入后台系统目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 配置API密钥
cp config/config.example.json config/config.json
# 编辑 config/config.json 设置你的LLM API密钥

# 运行部署脚本
python deploy.py

# 启动系统
python start.py
```

### 主要功能
1. **论文管理**: 维护论文列表，自动抓取论文内容
2. **LLM分析**: 生成背景解读、关键概念、论文亮点
3. **词汇提取**: 自动提取GRE/TOEFL/IELTS/AI专业词汇
4. **数据注入**: 通过小程序更新机制注入到用户本地
